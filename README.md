# انبار یار (Anbar Yar)

سامانه‌ی فارسی (RTL) مدیریت انبار، فاکتور فروش، خرید، امانی و آنالیز/پردازش برای کسب‌وکار عمده‌فروشی.


برنامه **Local-first** است: اطلاعات ابتدا روی همان دستگاه ذخیره می‌شوند. نسخه‌ی وب و فایل تک‌فایلی آفلاین، در صورت ورود به یک حساب مشترک، اطلاعات را به‌صورت خودکار با فضای خصوصی Supabase همگام می‌کنند. هنگام قطع اینترنت، کار محلی ادامه دارد و تغییرات پس از اتصال دوباره ارسال می‌شوند. قابلیت‌های اصلی برنامه و فایل آفلاین به اینترنت وابسته نیستند؛ فقط ورود ابری و همگام‌سازی به اینترنت نیاز دارد.

## استفاده
نسخه‌ی آنلاین: https://alirezahasheminezhad.github.io/anbaryar/

فایل `index.html` را دانلود و در مرورگر باز کنید (نیازی به سرور نیست).
نسخه‌ی تک‌فایلی آفلاین: داخل برنامه، تنظیمات ← «ساخت نسخه‌ی آفلاین».

## همگام‌سازی ابری
از بخش «پشتیبان‌گیری کلی» با Google یا لینک ورود ایمیلی (Magic Link) وارد شوید. دستگاه‌های مختلف باید به همان حساب وصل باشند. تغییرات روی هر دستگاه ابتدا محلی ذخیره شده و سپس به‌صورت خودکار به فضای ابری فرستاده می‌شوند؛ دستگاه‌های دیگر حداکثر در بازه‌ی بررسی بعدی آن را دریافت می‌کنند.

برای دکمه‌ی «اتصال گوگل به همین دستگاه»، گزینه‌ی **Allow manual linking** باید در Supabase → Authentication → Settings فعال باشد. در غیر این صورت از دکمه‌ی «ورود با حساب Google» استفاده کنید؛ اگر داده‌ی محلی دارید، در اتصال اولیه نسخه‌ی محلی را به‌عنوان مبنا انتخاب کنید.
اگر دو دستگاه هم‌زمان اطلاعات متفاوتی را تغییر دهند، برنامه هر دو نسخه را نگه می‌دارد و پیش از جایگزینی از کاربر انتخاب می‌خواهد. ورود اولیه روی دستگاهی که اطلاعات محلی دارد نیز نیازمند انتخاب بین نسخه‌ی محلی و ابری است.
اگر رمز امنیتی محلی فعال باشد، محتوای ابری رمزنگاری می‌شود؛ اولین دستگاه جدید برای بازکردن نسخه‌ی ابری رمز دستگاهی را که رمزنگاری را شروع کرده است یک‌بار وارد می‌کند. سپس کلید ابری در IndexedDB همان دستگاه، با کلید امنیتی محلی آن دستگاه رمز می‌شود تا پس از بستن و بازکردن دوباره‌ی نسخه‌ی آفلاین هم دوباره رمز ابری نخواهد. رمز محلی هر دستگاه مستقل است؛ اگر رمز محلی همین دستگاه تغییر کند، ممکن است رمز ابری یک‌بار دیگر برای بازذخیره‌ی امن لازم شود.

## توسعه
پیش‌نیاز: Node.js و Python. یک‌بار وابستگی‌ها را نصب کنید:
```bash
npm install               # نصب @babel/standalone برای پیش‌کامپایل JSX
python3 build.py          # src/ → index.html (JSX در Node پیش‌کامپایل می‌شود)
python3 build.py --check  # بررسی هم‌خوانی بایت‌به‌بایت (CI)
```
کد JSX در `src/app/*.jsx` است و `index.html` خروجیِ ساخته‌شده است (باید commit شود). از build 10.8 به بعد Babel در مرورگر اجرا نمی‌شود؛ کامپایل هنگام build انجام می‌گیرد.
ساختار و نقشه‌ی فایل‌ها: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — راهنمای هوش مصنوعی: [CLAUDE.md](CLAUDE.md)

> ⚠️ داده‌ی کسب‌وکار داخل ریپو نیست. از داخل برنامه مرتب پشتیبان (Backup) بگیرید.
