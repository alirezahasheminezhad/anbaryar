# انبار یار (Anbar Yar)

سامانه‌ی فارسی (RTL) مدیریت انبار، فاکتور فروش، خرید، امانی و آنالیز/پردازش برای کسب‌وکار عمده‌فروشی.
یک فایل HTML؛ داده‌ها فقط روی دستگاه کاربر (مرورگر) می‌ماند. بارگذاری اول برای دریافت کتابخانه‌ها به اینترنت نیاز دارد؛ نسخه‌ی کاملاً آفلاین و خودبسنده را از داخل برنامه بسازید.

## استفاده
نسخه‌ی آنلاین: https://alirezahasheminezhad.github.io/anbaryar/

فایل `index.html` را دانلود و در مرورگر باز کنید (نیازی به سرور نیست).
نسخه‌ی کاملاً آفلاین: داخل برنامه، تنظیمات ← «ساخت نسخه‌ی آفلاین».

## توسعه
پیش‌نیاز: Node.js و Python. یک‌بار وابستگی‌ها را نصب کنید:
```bash
npm install               # نصب @babel/standalone برای پیش‌کامپایل JSX
python3 build.py          # src/ → index.html (JSX در Node پیش‌کامپایل می‌شود)
python3 build.py --check  # بررسی هم‌خوانی بایت‌به‌بایت (CI)
```
کد JSX در `src/app/*.jsx` است و `index.html` خروجیِ ساخته‌شده است (باید commit شود). از build 10.8 به بعد Babel در مرورگر اجرا نمی‌شود؛ کامپایل هنگام build انجام می‌گیرد.
ساختار و نقشه‌ی فایل‌ها: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — راهنمای هوش مصنوعی: [CLAUDE.md](CLAUDE.md)

> ⚠️ داده‌ی کسب‌وکار داخل ریپو نیست. از داخل برنامه مرتب پشتیبان (Backup) بگیرید.
